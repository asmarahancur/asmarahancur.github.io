How It Works

This tool extracts just the domain name from any URL, removing:

  • HTTP/HTTPS protocols
  • Subdomains (optional)
  • Paths and filenames
  • Query parameters
  • Port numbers

Example Input

https://www.example.com/page
http://sub.domain.org/path/
blog.site.net/article?id=123
invalid-url
mydomain.com

Example Output

example.com
domain.org
site.net
mydomain.com
